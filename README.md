# BTM-v1.1
BTM v1.1 is a zero-RAM, $O(1)$ telemetry encoding protocol for space avionics. Powered by 2-adic decomposition and RISC-V hardware primitives (CTZ), it removes block buffering entirely. It yields deterministic streaming with up to 73% modeled RF energy savings. DOI: 10.5281/zenodo.22288196.
